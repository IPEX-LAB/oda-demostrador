# Espacio de nombres persistente

El perfil usa `https://w3id.org/oda-lab/` como espacio de nombres. w3id.org es un servicio gratuito de identificadores persistentes: si el repositorio cambia de sitio, basta con actualizar la redirección y los identificadores siguen funcionando.

Para registrarlo, se copia [`.htaccess`](.htaccess) en una carpeta `oda-lab/` de una copia (fork) de <https://github.com/perma-id/w3id.org> y se abre una solicitud de incorporación (pull request). Los responsables de w3id suelen revisarla en unos días.

La ficha web supone que GitHub Pages publica la rama `main` desde la raíz del repositorio, en `https://ipex-lab.github.io/oda-demostrador/web/`.
